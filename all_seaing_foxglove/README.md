# all_seaing_foxglove

Foxglove extension + layouts so [Foxglove](https://foxglove.dev) can replace RViz for the boat.
Foxglove connects to `foxglove_bridge` on the Jetson (`ws://jetson:8765`, started by
`vehicle.launch.py` and `perception_raw_rosbag.launch.py`). Unlike RViz on the laptop, this doesn't
slow the boat down: the bridge is a local subscriber on the Jetson and streams to the laptop over
its own WebSocket, dropping data when the network is slow instead of blocking publishers.

Not a ROS package (`COLCON_IGNORE`): it's a TypeScript extension that runs inside Foxglove.

## Extension (`src/`)
Message converters so Foxglove's built-in panels display our messages:

| Message | Shown as | Where |
|---|---|---|
| `all_seaing_interfaces/ObstacleMap` | `foxglove.SceneUpdate`: centroid, convex hull, label text (colored by label) | 3D panel (replaces the `all_seaing_rviz_plugins` ObstacleMap display) |
| `all_seaing_interfaces/LabeledBoundingBox2DArray` | `foxglove.ImageAnnotations`: YOLO boxes with label and confidence | Image panel, as an annotation of the raw camera image |
| `all_seaing_interfaces/LabeledObjectPlaneArray` | `foxglove.SceneUpdate`: banner planes (thin box + normal arrow + label) | 3D panel |
| `geometry_msgs/PointStamped` (e.g. `/clicked_point`) | `foxglove.SceneUpdate`: sphere | 3D panel |

Label names/colors come from `src/labels.ts`, a copy of
`all_seaing_bringup/config/perception/all_label_mappings.yaml` (keep in sync).

Install (needs Node.js):
```bash
cd all_seaing_foxglove
npm install
npm run local-install   # into the Foxglove desktop app; restart Foxglove
# or: npm run package -> arcturus.all_seaing_foxglove-<version>.foxe, drag it into Foxglove (also works in the web app)
```
Develop: edit `src/`, then `npm run lint && npm run local-install`.

## Layouts (`layouts/`)
Foxglove equivalents of our RViz configs, generated by `layouts/rviz_to_foxglove.py`:

| Layout | From |
|---|---|
| `dashboard.json` | `all_seaing_bringup/rviz/dashboard.rviz` (with satellite Map panel) |
| `perception.json`, `perception_roboboat.json`, `lio.json`, `amcl_pose.json`, `default.json` | personal RViz configs |

Import in Foxglove: Layouts > Import from file. Every layout has a 3D panel (all the RViz displays,
same topics visible), an Image panel per RViz image display (raw camera images get the YOLO boxes
overlaid), a Diagnostics panel, and, where RViz had an AerialMap, a Map panel following the GPS fix
with the offline tiles served by the control panel (`http://localhost:8080/tiles/{z}/{x}/{y}.png`,
so the control panel must be running for satellite imagery).

Convert another RViz config: `python3 layouts/rviz_to_foxglove.py <file.rviz> [-o layouts/]`.
